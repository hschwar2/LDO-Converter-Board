# Simple LDO Converter PCB

A compact, custom-designed Printed Circuit Board (PCB) for a Low Dropout (LDO) voltage regulator circuit, designed in Altium Designer.

## Project Overview

This repository contains the manufacturing output files (Gerber files and Altium CAM work files) for the **Simple LDO Converter**. The board is configured as a standard 2-layer PCB designed for custom power management applications.

## Design Specifications

* **Design Tool:** Altium Designer

* **Layer Count:** 2 Copper Layers (Top is signal and bottom is ground)

* **Assembly Type:** Surface Mount and Through-Hole

* **Units:** mm
